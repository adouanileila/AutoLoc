\# AutoLoc



\## Objectif du projet



AutoLoc est une plateforme de gestion de location de véhicules multi-agences.



Le système permet de gérer les activités liées à la location de véhicules au sein de plusieurs agences.



\## Acteurs



\- Client

\- Agent d'agence

\- Responsable d'agence

\- Administrateur



\## Technologies



\- Java 17+

\- Spring Boot

\- Maven

\- MySQL

\- Git / GitHub

\- Postman

\- IntelliJ IDEA Ultimate
